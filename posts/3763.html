天权-实习那些事02

小米里的大麦2026-04-272026-05-09

2026.04.27

按照之前说的，本来是要让我正式接触 Node.js、空间算法、Puerts 这些的，但我顺手给老大演示了一下我自己电脑上的 AI 本地化方案。可能是因为他觉得我对 AI 这块有一些自己的想法，于是就让我先试着用 OpenCode 接公司本地模型。啊？也就是几天时间，公司就将 AI 本地化了，看样子我成为公司 AI 专家是没指望了……

OpenCode 对接公司本地的 AI 这个事情我涉及过，比较简单，所以我很快就跑通了，后面又在另外几台机器上装上 OpenCode，并接入本地模型做进一步测试。不过在实际使用过程中，我也逐渐察觉到一些问题：输出格式有点奇怪、上下文明显偏短，而且幻觉比较高，很容易在回答里自我循环，不算特别好用。

2026.04.28

今天老大交给我一个 Java 项目 —— 境外地名自动翻译平台，以及一份 1400+ 页的 PDF，想让我借助 OpenCode 处理这个项目里的问题。看完那份 PDF，确实有点被数量震住了：

测试项目境外地名自动翻译平台
问题数量4076
语言类型JAVA
文件个数606
代码行72702
代码注释率11.99%
注释行8715
空行5272
可执行代码行58715

那就改吧。过程中认识了旁边的一个实习生，说看我蛮懂 AI，想加个绿泡泡认识一下 😁，别人都主动了，总不能拒绝是吧 😏，但她的基础是蛮差的 😅，简单教了她一下 Git 和 AI 的使用就下班了。今天我走得很晚，和老大聊了不少，才知道这个 Java 项目是外包出去的，且不涉密。至于那份 1400+ 页的 PDF，据说是机器检测出来的……

其实我还挺好奇是什么机器能把问题检测得这么细。PDF 里的内容非常明确，FATAL、ERROR、WARNING 的占比都列得很清楚，每个问题也写得比较详细，甚至有些地方还直接给了修正建议。

2026.04.29

今天把这个 Java 项目处理完并提交给老大了。虽然我并不算熟 Java，但借助 AI 工具，最后还是把 4076 个问题压到了 100 个以内。另外，我也顺手把 Git 备份和 AI 工具出错后如何及时回滚的技巧，分享给了其他同事。

2026.04.30（上午）

今天只上了上午半天班，下午请假回学校了，不理解学校为什么每次放假都要严格考勤 🤬。不过就在这小半天里，我发现了一个比较关键的问题：

公司部署的本地模型是 Qwen 3.6-35B-A3B，理论上下文大小是 256K，但实际体验下来，上下文明显小得多，感觉只有 16K 左右。我用 Hermes Agent 分别设置了 3 个不同大小的上下文值，做了几轮测试，基本验证了自己的判断。这样一来，之前接入 OpenCode 测试时那些奇怪现象也就说得通了。于是我把这个问题反馈给老大，到了下周一（2026.05.06）得到确认：确实存在这个问题，后来把上下文调高后，整体表现就正常多了。

后面就匆匆回学校了……

2026.05.06

今天换到了一台新机器，系统是 统信 UOS（专业版 1050）。我先在这台机器上装好了 Hermes Agent，随后开始接触 UE 虚幻引擎，并尝试用源代码把它编译运行到统信 UOS 上，顺手还编译了另一个相关库（具体名字记不太清了，可能是 Vulkan ？）。因为有 AI 辅助，整体推进得比预想中快不少，没用多长时间就干完了，老大似乎有点震惊到：“我去，这么快？！”

后面又需要加一个 Cesium for Unreal（2.13.0） 插件，花了一些时间也顺利完成了，游戏 Demo 也能正常跑起来，👉 有点意思！！缺点是这个统信系统每次启动 UE 都要很久，体验很差。临近下班时间，再次忍不住和老大洽谈起来，老大跟我们讲了他的愿景：

  • 希望彻底改变当前工作现状，所有工作涉及的软件操作集成到一个平台
  • 所有东西只需要通过内网传输，不走网络、不通过第三方服务器
    1. 其实这也 正是我想做 的，我 非常渴望毕生有幸研发或参与 到这样的项目：
      • 天生具有 端到端加密 的功能，通讯过程完全端到端加密，最好加上里三层外三层路由
      • 极致的性能（要达到军工光缆的效果）、美观的 UI、极致便捷方便
      • 不使用任何信息（手机号、邮箱）匿名进行注册、账号 ID 不泄露用户任何信息
      • 去中心化网络结构，不记录 IP 信息、不收集用户任何信息、也不存储任何数据、阅后即焚
      • 普惠全球人民，使用门槛低的要像喝水一样简单，使用上第一时间想到的不是 X 信、不是 TG！
    2. 听起来这似乎就是 Session 是吧，但也确实没错！因为我觉得 Session 还有很多地方需要改进。
  • 每个人有自己的私人助手，产品经理等人员可以自动总结出周报、人员是否离职/是否请假/是否出差、任务进度/日程等状况一眼清楚
  • 知识库共享，大家只需要将文件丢入知识库，就能共享到所有人的知识，内置大模型，可以针对性回答（可能是想要 RAG 增强版效果）
  • ……

我们想聊甚欢，最后回到现实，老大推荐我可以了解了解 CopilotKit。

不得不说这个统信和麒麟真是路边一条，国产的系统真的难用！

2026.05.07

今天电脑状态有点离谱，UE 怎么都启动不起来，一启动就崩溃 🤣。我把 Cesium for Unreal 插件装了又移、移了又装，重启也试过，能想到的办法基本都试了一遍，还是不行。老大上午不在，我就先自己尝试把 CopilotKit 装起来。

下午老大回来了，我们一起折腾了半天还是没彻底解决，于是又换了一台新机器。随后我简单学习了一下 CesiumForUnreal 在 Windows 下交叉编译 Linux 版本 的流程，不断处理中间出现的报错，最后还是把一个游戏 Demo 成功打包并运行了出来。

2026.05.08

今天先帮一位非技术同事安装并配置好了 Hermes Agent，也对接好了公司的本地模型，顺便介绍了一些基本使用方法和技巧。后面梅开二度，这台机器又出了问题，正用着突然就找不到 Linux 所需的 SDK 了，还存在一些其他问题 🙃，只能继续排查……为了提升效率，下午老大又给我换了一台配置相当不错的新机器：

  • CPU： i9-12900HX，16 核 24 线程
  • 内存： 64 GB，DDR5 4800，双通道
  • 显卡： NVIDIA GeForce RTX 3080 Ti Laptop GPU，16 GB 显存
  • 硬盘： 两个 NVMe SSD 有好几 TB，容量非常充足

不得不说，机器一换，效率提升非常明显——在统信 UOS 上要一个小时的任务，放到这台机器上不到十分钟就能跑完。后面主要就是不断增删插件、反复打包项目，最后仅遗留了一个 WebUI 相关问题暂时没解决，其他均正常！

除此之外，今天还看到 XXXXXXXXXXXXXX 出入证（保密处理）；晚上老大还提到，希望我准备一下后续讲课 / 分享的事情……

2026.05.09

今天把一个和 AFSIM（一个由 AFRL 开源的军事仿真框架）相关的东西编译好了，也把整个过程沉淀成了文档，功能可以正常使用。与此同时，Windows 侧的 UE 相关内容也一起打包好了。此外，我还为 Hermes Agent 增加了一个面向 AFSIM 工作场景的 skills。

按老大的说法，以前这个事情让 XX（高级软件工程师）来做，通常需要 1 天多，而我配合 Hermes Agent 大概 3～4 个小时 就完成了，速度大大超出他的预期。当然，如果机器别那么卡，应该还能再快一点 😏。

晚上回去后在思考后面该怎么去“讲课”。说实话，我觉得老大给我的任务边界还不是特别明确，AI 赋能这块能讲的东西太多，一时间还真不知道从哪切入更合适。此外，今天还新增了一个陕西天权的企业微信。
