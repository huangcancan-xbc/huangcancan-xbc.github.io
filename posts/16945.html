天权-实习总结

小米里的大麦2026-06-242026-06-30

实习总结

2026.04 – 2026.06，在陕西航天宏图 / 天权时空的空天产品研发部待了大约两个月。这篇是我自己对这段经历的整理，也方便以后翻看。

1. 基本信息

项目内容
实习单位陕西航天宏图信息技术有限公司 / 陕西天权时空智能科技有限公司
所属部门西安-空天产品研发部
实习时间2026 年 4 月 14 日 – 2026 年 6 月 18 日（约 2 个月）
岗位方向C++ 开发实习生（实际工作覆盖全栈开发 / AI 工程化）

中途有一次 “系统层面” 的离职：2026.06.08 提交离职单，从航天宏图转到天权。实际一直在同一个分/子公司、同一个部门、跟同一个老大，只是挂名换到了天权。

2. 这段日子在做什么

1. 跟系统和编译较劲

进公司分到的第一台机器是银河麒麟 V10，没 Qt 环境，老大的意思是 —— 从 Qt 源码编出 Qt 环境。我一开始觉得 “编译嘛，能有多难”，然后被教做人：每轮构建 2 小时以上，连着失败 3 遍，编译日志比命还长。最后排查出是系统权限和少量环境问题，才编出来。

后面这一类活接连不断：

  • 军工涉密系统插件模块编译：6GB+ 体量的项目，上千条写死的绝对路径改成相对路径，中间夹着 qmake 报错、依赖缺失
  • UE 虚幻引擎：在统信 UOS 上从源码编译 UE，补 Cesium for Unreal 插件，再做 Windows 交叉编译 Linux 版本
  • AFSIM 军事仿真框架：编译、打包、沉淀文档，给 Hermes Agent 加了一个面向 AFSIM 工作场景的 skill。按老大的说法，这事以前高级工程师要做 1 天多，我配合 Hermes Agent 大概 3–4 小时完成
  • Qt 项目注释：给一个 Qt 项目补注释，一万多行，注释率从约 13% 提到 27%

这段最常做的事，不是安安稳稳写业务，而是先把环境、依赖、系统理顺，再想办法让东西跑起来。统信和麒麟是真的难用，同一件事在统信 UOS 上要 1 小时，换到 i9-12900HX + 64G + RTX 3080 Ti 的新机器上不到 10 分钟 —— 机器差距比系统差距更狠。

2. 几个项目

1. 天权星控系统

这是我这段时间的主要/主线大项目，星控算法测试和地面与卫星通信模拟都是它的核心模块。我参与的就是这两块：星控算法测试，做 Docker 打包、启动验证，前端小范围完善，Python 后端 BUG 修复和功能补充；地面与卫星通信模拟，这是用 C++ Qt 写的，我主动修了这里的 BUG，再做 Windows 和 Ubuntu 双平台打包，适配 ARM 架构的嵌入式 Linux 板子，用旧/假数据做验证，最后打包部署到正点原子开发板上。

2. 境外地名自动翻译平台（Java）

老大丢给我一个外包交付的 Java 项目，外加一份 1400+ 页的 PDF：4076 个问题，606 个文件，72702 行代码。我本身不算熟 Java，最后借助 AI 工具把问题数压到 100 以内。顺手把 Git 备份、AI 出错回滚的工作流分享给了同事。

3. 内网文件全流程管控系统

这是临走前最完整的一件事 —— XX（高级软件工程师）交给我，从搭建、完善、改 BUG 到交付 + 写交接文档和部署方法，全程一个人跟下来。走之前还和 XX 一起聊了怎么把交换机和这套系统结合起来，做内网 “实名” 标定上网的管控。

3. AI 工程化（我自己撬出来的一条线）

本来老大让我去碰 Node.js、空间算法、Puerts。我顺手给他演示了我自己电脑上的 AI 本地化方案，事情就拐弯了 —— 他让我先用 OpenCode 接公司本地模型。几天时间公司就把 AI 本地化了，老登原来那句 “你就成公司 AI 专家了” 的玩笑也就此作废 🤪。

这条线后面越铺越长：

  • 本地模型对接：把 Qwen 3.6-35B-A3B 接进 OpenCode，多台机器部署测试。期间发现输出格式奇怪、上下文明显偏短、幻觉高，用 Hermes Agent 设了几组不同的上下文值测了几轮，基本确认实际只有 16K 左右（标称 256K）。反馈给老大，节后确认确实有问题，调高后表现才正常
  • Hermes Agent 推广：给运营总监、总经理助理、多位运维同事安装配置、对接本地模型、讲使用方法
  • 多 Agent 协作：研究 Hermes Agent 的 Kanban，建了项目管理员、开发专家、测试专家几个 Profile，跑通多 Agent 协作，出了案例和使用方法
  • CopilotKit 集成：用 Hermes API 接 CopilotKit，做了一个生成式 UI 的 PoC
  • 知识库调研：试了 LLM_wiki、AnythingLLM 等方案，验证和 Hermes Agent 结合的可行性

4. 一个人进所里

一段我独自进到保密所里，在国防麒麟系统上部署软件的奇妙经历……

5. 实习生给公司培训

入职不到一个月，老大让我给公司做一次 AI 工具使用的培训。17:30 开始，讲到 18:50 左右。硬着头皮上的，但讲完至少说明：我不只是自己折腾，也能把我的经验技能和试出来的东西整理出来讲给别人听。

3. 这几天遇到的那些人

  • 老大是部门总监，非常和蔼可亲。他讲课是启发式/苏格拉底式的，生怕我不会，会专门用很多示例。

  • 老登是我最先熟的同事，32 岁看着像 25 岁，年轻、有意思、聊得来，算我的小老大。很多业务、项目、见闻，都是和他聊出来的。

  • 运营总监像老顽童，体验完 Hermes Agent 专门跑来跟我夸一顿 🤣。

  • XX（高级软件工程师）很忙，但给的那版封装脚本真的省了我很多事。我很想跟他多学点，但他确实忙得没空搭理我 😅。

  • 旁边坐过一个实习生，基础一般，我教了她一点 Git 和 AI。她离职那天很突然，一句轻轻的 “拜拜，祝你顺利” 就临别了……

  • ……

4. 回头看

这段实习不是那种每一步都很标准、很顺的经历。相反，它经常伴随陌生系统、奇怪环境、临时变化、信息不全。但也正因为这样，它没让我停留在 “看起来会”，而是逼着我真上手、真排查、真把事情做完。

我不太怕新东西。系统换了、机器换了、环境变了，哪怕一开始不熟，我也愿意先自己啃一轮，再一点点理顺。我也不太排斥那些看上去 “有点杂” 的活 —— 编译、打包、部署、调试、写文档、做交接、讲使用方法，单拎出来都不算耀眼，但合在一起反而更接近真实工程的日常。

老大说过一句话，说这就是大型项目最真实的样子。信息常常不全，问题不是照着文档就能解决，环境也不总是友好 —— 光盘拷出来文件缺失、新机器找不到 SDK、换台机器要重头编译一遍。但这些都不是停下来的理由，最后总得想办法把事情往前推。慢慢适应了这种节奏之后，我觉得这种 “在不太理想的条件下还能往前推” 的能力，比会多少个新名词更重要 —— 它让我从 “照着教程做能跑就行” 慢慢往 “出了问题能自己扛住、把它收尾” 靠，还是很锻炼人的。

AI 这条线是我自己争取来的，不是被安排的。从顺手演示、到接本地模型、到发现上下文问题、到 Hermes Agent 落地和推广，整个过程让我越来越确定：AI 不是替代开发者的工具，而是让开发者更强大的杠杆。这也是我后面想继续往下走的方向。

实习的过程中也涨了不少见识，慢慢看到我认知之外原来还有这么多奇奇怪怪和复杂的要求，其实市场需求还是挺充裕的 🧐？同时也学到了一些门道。这段日子也不单单是工作上的，认识了一些人，经历了很多事，也是第一次真正从学校出来、落到社会里。让我意识到自己还有许多东西要学、很多事情要干。这是一段不错的经历，会让我怀念，但更多的是期待……

5. 几个我记得的数字

  • Java 项目问题数从 4076 压到 100 以内
  • Qt 项目注释率从约 13% 提到 27%，写了一万多行注释
  • AFSIM 编译打包，以前高级工程师要做 1 天多，我配合 Hermes Agent 大概 3–4 小时
  • 本地模型标称 256K 上下文，实测大概只有 16K
  • 同一件事在统信 UOS 上要 1 小时，换到那台新机器上不到 10 分钟
  • 给公司讲课讲了 80 来分钟

6. 这段实习碰过的东西

不是技术栈清单，只是实习期间接触过的东西。有些用得多、算是上手了；有些只是当时用一下，现在忘得差不多了 🤣，列在这里权当个记录。

  • 操作系统：银河麒麟 V10（国防）、统信 UOS、Ubuntu、Windows
  • 编程语言：C++、Python、Java、JavaScript
  • 框架/引擎：Qt、UE 虚幻引擎、Cesium for Unreal、CopilotKit
  • 工具/平台：Docker、Git、Nginx、MySQL、Redis、RabbitMQ、Postgres
  • 仿真：AFSIM（军事仿真框架）
  • AI 相关：Hermes Agent、OpenCode、Qwen 本地模型、多 Agent 编排、RAG 知识库
